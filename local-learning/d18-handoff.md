## 完整流程与理解复盘

调用方配置规则 → Harness → Agent → 运行循环 → 找到工具并检查参数 → 规则判断 → 执行或拒绝 → 保存结果并交给模型。

规则允许后，工具原有的路径范围等检查仍生效。规则拒绝时不进入实际操作，按原调用编号返回拒绝原因。学习者已在对话中说明“参数格式正确不代表规则允许”，并在本章复盘回答“规则拒绝了，文件就不会被修改”。据此记录为有指导复盘，不据此声称独立完成全部设计或实现。核心实现含学习者手敲及按授权由助手代写、修复；测试和演示脚本由助手准备。
